# 곡명 새 곡 시작
@ 작사·작곡 / CCLI 저작권 표기
[1절] [후렴] [브릿지] 구간 시작
한 줄 = 화면의 한 행. 구간 안에서 2줄씩 자동 묶음 (홀수면 마지막은 3줄)
빈 줄 = 강제로 다음 슬라이드
> 1절, 후렴, 2절, 후렴, 브릿지, 후렴 x2 진행 순서 (없으면 적힌 순서대로)
→ / Space / PageDown : 다음
← / PageUp : 이전
1~9, 0 : 해당 곡 제목으로
Home / End : 처음 / 끝
B : 검은 화면 전환
F : 전체 화면
E : 가사 편집
T : 하단 차례·곡 구성 켜기/끄기
? : 이 도움말
